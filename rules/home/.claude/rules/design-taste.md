## Design taste
Add a line here each time the user corrects a design.
- No AI/SaaS palette: no purple or violet gradients, no cyan→navy→purple mesh.
- Offer calm directions first: monochrome, one hue, warm or off-white.
- Native apps use the platform's system font and controls unless the user asks otherwise.
- For motion and interaction polish, use the skills `emil-design-eng`, `apple-design` and the
  animation skills.
