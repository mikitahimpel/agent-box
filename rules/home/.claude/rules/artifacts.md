## Artifacts
- Save anything the user should see (screenshots, videos, reports, generated images) in a
  new folder from `artifact-dir <topic>`, for example `artifact-dir memoxia-onboarding`.
  Start the topic with the project name when there is one.
- Print the full path of each file at the end.
- Scratch files stay in the session scratchpad. Files go into a repo only when they are part
  of the project (an asset, a store screenshot).
